Lottie

기본 사용법 — data-lottie (nhasset-ui-myd.js / uiSetLottie)

class="lottie" 엘리먼트에 data-lottie(컨테이너 자신을 다시 찾는 데 쓰이는 인스턴스 이름이라 페이지 내에서 고유해야 함), data-lottie-loop, data-lottie-path(content/nhmyd/js/lottie/ 안의 파일명, 확장자는 .js지만 내용은 JSON)를 적으면 nhasset-ui-myd.js의 uiSetLottie()가 window load 시점에 $('[data-lottie]')를 스캔해 재생합니다. update-ui.js와 무관하게 항상 로드되는 스크립트라 nds 화면이 아니어도 그대로 동작합니다. 다만 이 방식은 자동 크기·비율 지정이 없어 style로 폭/높이를 직접 잡아야 하고, data-lottie-path 경로 조합에 encodeURIComponent 처리가 없어 파일명에 공백을 쓰면 안 됩니다.

기존 2026 JSON 자산 재사용

images/update/json의 파일들을 내용 변경 없이 content/nhmyd/js/lottie/에 .js 확장자로 복사해 레거시 방식으로도 바로 불러올 수 있게 해뒀습니다. 원본 중 공백이 포함된 Rain Umbrella · Windy Tree · Wide Sample은 레거시 경로 조합에 encodeURIComponent 처리가 없어 그대로 쓰면 깨지므로, 이미 폴더에 있던 공백 없는 rain-umbrella · windy-tree · wide-sample(내용은 동일, 파일명만 다름)을 대신 복사했습니다.
